# Contact Book – Python Mini Project

A simple **console-based Contact Management System** developed using **Python**.  
This project allows users to **store, search, update, and delete contacts** using **CSV file handling** for persistent storage.

---

## Features

- Add new contacts  
- View all saved contacts  
- Search contacts by name or phone number  
- Update existing contact details  
- Delete contacts  
- Menu-driven console interface  
- Data stored permanently in CSV format  

---

## Technologies Used

- Python 3  
- CSV File Handling  
- Console / Terminal
